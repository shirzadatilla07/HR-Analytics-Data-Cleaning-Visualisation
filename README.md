# 📊 HR Analytics: Data Cleaning & Tableau Visualization

Bu layihədə HR (İnsan Resursları) məlumatları Python vasitəsilə təmizlənmiş, emal olunmuş və nəticələr Tableau vasitəsilə vizuallaşdırılmışdır.

---

## 📁 Layihə Faylları (Project Files)

* 🐍 **`HR_Anlayze.ipynb`** (və ya `.py`) — Python-da məlumatların təmizlənməsi və analizi kodu.
* 📄 **`hr_analytics_clean.csv`** — Python vasitəsilə təmizlənib eksport olunmuş məlumat seti.
* 📊 **`HR_Analyze.twbx`** — Məlumatlar əsasında hazırlanmış Tableau vizualizasiya / dashboard faylı.

---

## 🛠️ İstifadə Olunan Texnologiyalar

- **Python** (Pandas, NumPy) — Məlumatların təmizlənməsi (Data Cleaning) üçün.
- **Tableau Desktop** — Dashboard və vizuallaşdırma üçün.
- **CSV** — Təmizlənmiş dataların saxlanması üçün format.

---

## 🧹 Məlumatların Təmizlənməsi Addımları (Python)

Python skriptində aşağıdakı data cleaning əməliyyatları aparılmışdır:
1. **Daxil olan məlumatların analizi:** Boş və lazımsız sətir/sütunların müəyyənləşdirilməsi.
2. **Missing Values (Məlumat boşluqları):** Boş xanaların silinməsi və ya düzgün dəyərlərlə əvəzlənməsi.
3. **Data Types (Məlumat tipləri):** Sütun tiplərinin (tarix, rəqəm, mətn) düzgün formata gətirilməsi.
4. **Export:** Təmizlənmiş data Tableau-da istifadə üçün `hr_analytics_clean.csv` olaraq yadda saxlanıldı.

---

## 🚀 Tableau Vizualizasiyasını Necə Açmalı?

Tableau dashboard-unu kompyuterinizdə baxmaq üçün:

1. Bu repozitoriyada olan **`HR_Analyze.twbx`** (və ya `.twb`) faylını kompyuterinizə yükləyin (download edin).
2. Faylı açmaq üçün kompyuterinizdə **Tableau Desktop** və ya pulsuz **[Tableau Reader](https://www.tableau.com/products/reader)** proqramının olması kifayətdir.
